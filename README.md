# Python-Project3

A collection of Python practice programs and small projects, covering control flow, data structures, functions, string handling, and file/error handling.

## 📂 Files

| File | Topic |
|---|---|
| B_Calculator.py | Calculator program |
| B_N_Guess_Gam.py | Number guessing game |
| String4.py | String operations |
| Control_Flow5.py | if/else and loops |
| Data_Structures6.py | Lists, tuples, dictionaries, sets |
| Function7.py | Functions |
| Fil_err_handling8.py | File handling and error handling |
| Practice_Project.py | Practice project |
| Project_1.py – Project_4.py | Small projects |

## ▶️ How to Run

Make sure Python 3 is installed, then run any file:

```bash
python B_Calculator.py
```
